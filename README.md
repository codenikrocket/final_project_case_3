# Генератор тестовых данных (Кейс №3)

## 📌 Описание проекта
Проект представляет собой комплексную систему на Python для генерации, валидации, анализа и экспорта реалистичных персональных тестовых данных. Разработан в рамках итоговой проектной работы (Кейс №3).

Инструмент позволяет массово создавать фейковые профили пользователей (ФИО, email, адреса, телефоны, даты рождения) и выгружать их в форматы `CSV` и `JSON`. Выгрузка в `CSV` адаптирована для интеграции с корпоративными CRM-системами (например, Битрикс): используется кодировка `utf-8-sig` (для корректной работы в Excel) и разделитель `;`.

## 🚀 Ключевые возможности
* **Умная генерация:** Использование библиотеки `Faker` для создания реалистичных данных и алгоритмов транслитерации для формирования email-адресов на основе ФИО.
* **Валидация форматов:** Проверка корректности сгенерированных email-адресов (RegEx) и дат.
* **ML-контроль качества:** Применение алгоритма машинного обучения `IsolationForest` (из библиотеки `scikit-learn`) для автоматического поиска аномалий в данных (например, несоответствие возраста и длины email).
* **Аналитика и визуализация:** Построение графиков распределения по возрасту и полу с помощью `pandas`, `matplotlib` и `seaborn`.
* **Консольный интерфейс (CLI):** Удобное пошаговое взаимодействие с пользователем для настройки объема данных и формата экспорта.

## 🛠 Технологический стек
* **Язык:** Python 3.x
* **Библиотеки:** Faker, pandas, scikit-learn, matplotlib, seaborn
* **Архитектура:** Модульная (генератор, валидатор, ML-анализатор, экспортер)

## 📁 Структура проекта
```text
final_project_case_3/
│
├── src/
│   ├── analytics.py      # Графики распределения по полу и возрасту
│   ├── exporters.py      # Сохранение результатов в CSV (для Excel/CRM) и JSON
│   ├── generator.py      # Генерация профилей через Faker и создание email по ФИО
│   ├── ml_quality.py     # Поиск аномальных данных с помощью IsolationForest
│   ├── ui.py             # Консольное меню для ввода параметров
│   └── validators.py     # Проверка корректности email и форматов дат
│
├── exports/              # Папка для сгенерированных файлов и графиков
├── main.py               # Главный скрипт (запуск и связка всех модулей)
├── requirements.txt      # Список сторонних библиотек
└── README.md             # Документация проекта
```

## ⚙️ Установка и запуск

1. Склонируйте репозиторий на свой компьютер:
```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
```

2. Перейдите в папку проекта:
```bash
cd final_project_case_3
```

3. Установите необходимые зависимости из файла:
```bash
pip install -r requirements.txt
```

4. Запустите главный скрипт:
```bash
python main.py
```

5. Следуйте инструкциям в консоли (введите количество записей и нужный формат сохранения). Готовые файлы и графики появятся в папке `exports/`.
